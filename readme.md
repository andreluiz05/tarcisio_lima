## 🚀 Sobre o Projeto

Este projeto é o site oficial de apresentação e vendas de shows do cantor **Tarcísio Lima**. O objetivo foi criar uma página de alta performance, com design elegante (fundo escuro e dourado) e foco total na conversão (botões de WhatsApp e Agenda).

### ✨ Funcionalidades Principais

* **📱 Totalmente Responsivo:** Layout adaptável para Celulares, Tablets e Desktop.
* **🎨 Design Premium:** Estética moderna utilizando variáveis CSS para fácil manutenção.
* **⚡ Alta Performance:** Site estático, com carregamento instantâneo.
* **🔍 SEO Otimizado:** Meta tags dinâmicas para Google, Facebook e WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas de desenvolvimento web moderno:

* **HTML5 & CSS3:** Semântico e estilizado com CSS Variables e Flexbox/Grid.
* **JavaScript (Vanilla):** Scroll Reveal (animações), Carrossel da Agenda e Menu Mobile.
